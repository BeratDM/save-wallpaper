📋 Overview

save-win11-wallpaper is a Python utility that extracts the current Windows 11 desktop wallpaper from the system's TranscodedWallpaper file and saves it as a timestamped PNG image to a folder of your choice. It checks for duplicates by file hash so you never save the same wallpaper twice.

🖥️

CLI & GUI

Use from the command line for scripting, or launch the friendly GUI for one-click saving.

🔍

Duplicate Detection

SHA-256 hashing ensures every saved image is unique — no more duplicate wallpapers cluttering your folder.

⚙️

Persistent Config

Set and forget your default save folder via the GUI settings or config set command.

📅

Timestamped Files

Saved files follow the wp-YY-MM-DD-ffffff.png naming scheme for easy sorting.

🚀 Get Started

Option 1: Download the pre-built .exe (recommended)

Grab the latest getwallpaper.exe from the Releases page — no Python required.

Usage after download
getwallpaper.exe save "C:\Users\YourName\Pictures\Wallpapers"
getwallpaper.exe               (launches the GUI)
Tip: Add the folder containing getwallpaper.exe to your PATH so you can run it from anywhere.

Option 2: Run from source

Clone & run
git clone https://github.com/BeratDM/save-win11-wallpaper.git
cd save-win11-wallpaper
python main.py
Note: This tool is designed for Windows 11 and relies on Windows-specific paths under %APPDATA%\Microsoft\Windows\Themes. No third-party dependencies are needed — only the Python standard library.

⌨️ CLI Usage

All commands work identically with getwallpaper.exe (downloaded release) or python main.py (source):

Save wallpaper to the default folder
getwallpaper.exe save
Save wallpaper to a specific folder
getwallpaper.exe save "C:\Users\YourName\Pictures\Wallpapers"
View current default folder
getwallpaper.exe config get
Set a new default folder
getwallpaper.exe config set "C:\Users\YourName\Pictures"
Show help
getwallpaper.exe help

If running from source, replace getwallpaper.exe with python main.py.

🖱️ GUI Usage

Launch the GUI by running getwallpaper.exe (or python main.py) without arguments:

getwallpaper.exe
Save Windows Wallpaper
Destination: ⚙ Settings
Default folder ▼ X:\Files\Wallpapers\n1\x\ Browse
Ready
Save Wallpaper

How the GUI works:

  1. Destination — Choose between Default folder, Current directory, or Specify... a custom path.
  2. Settings (⚙) — Open the settings dialog to change your default folder permanently.
  3. Browse — Pick a folder interactively.
  4. Save Wallpaper — Saves the current wallpaper. Shows status messages and an Open Folder button on success.

⚙️ Configuration

The configuration file is stored at:
%LOCALAPPDATA%\BRT-SaveWallpaper\config.json

Example config.json
{
  "default_folder": "X:\\Files\\Wallpapers\\n1\\x\\"
}

The default save location is hardcoded in config.py as WP_DEFAULT. You can change it via the config set CLI command or the GUI Settings dialog.

🔨 Build from Source

If you prefer to build the executable yourself using PyInstaller:

Build command
pip install pyinstaller
pyinstaller main.spec

The spec file is included in the repository. The built executable will be placed in the dist/ folder and can be distributed without requiring Python.

Alternatively, just grab the pre-built getwallpaper.exe from GitHub Releases.

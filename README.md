# save-wallpaper

Save wallpapers you love to a folder in Windows. Usable from the CLI and GUI.

Save 1 minute every day. (I spent more time automating it.)

![img](https://pub-55a8605bd8ee494ab002c0bb70e15fed.r2.dev/github/w11wp.PNG)

- SHA-256 hashing for duplicate detection
- Storing the settings in `AppData` for persistent config
